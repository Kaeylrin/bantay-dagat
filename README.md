# Bantay Dagat

An IoT-Based Water Quality Monitoring System built with React, Vite, TailwindCSS, Express, and Firebase Realtime Database.

## Features
- **Real-time Monitoring:** Receives live sensor telemetry from Arduino.
- **Historical Water Quality Trends:** Analyzes water quality parameters (pH, Temperature, Air Temperature, Humidity, Turbidity) over time.
- **Go / No-Go Decision Support:** Evaluates safety thresholds to ensure conditions are perfect for sea turtle release.
- **Admin Panel:** Secure management of Ranger accounts and credentials.

## Local Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```

## Live Deployment
Deploys automatically to Vercel upon pushes to the `main` branch.
